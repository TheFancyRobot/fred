<context>
The UAT is revealing real bugs in the TUI and runtime lifecycle beyond phase 45.1's scope. The runtime invalidation/rebuild cycle is fragile — state (storage adapters, agents, etc.) applied to one runtime instance is lost when `invalidateRuntime` destroys it and a new one is created. The `applyRuntimeState` function replays tools, providers, intents, workflows, and default agent ID, but does NOT replay agents themselves or the storage adapter. The storage adapter fix was added to `invalidateRuntime` but agents still aren't replayed (they're expected to be registered after the last invalidation in the init sequence, which the Bug 2 fix ensures).

The OpenRouter content format bug is the next critical fix. The `@effect/ai` Prompt encoding uses typed part arrays for content, but OpenAI-compatible APIs expect plain strings for user/assistant messages (arrays are only valid for multi-modal content). The fix should ensure that single-text-part arrays are coerced to plain strings before reaching the API.
