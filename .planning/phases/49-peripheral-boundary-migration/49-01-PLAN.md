Violation 1 (line 68 - `runEffectWithTestClock`): Convert to return `Effect.Effect<A, E>` instead of `Promise<A>`. Rename to `withTestClock` for clarity. Keep the `Effect.gen` body (fork, adjust, join) identical but return the composed Effect with `TestContext` provided. Actually, simpler approach: The `createReplayOrchestrator.replay()` method is itself an async boundary (it returns `Promise<ReplayResult>` and is called from CLI eval commands). Keep `runEffectWithTestClock` as-is but move the `Effect.runPromise` into the caller (`replay()` method) instead. Create `withTestClock` returning Effect. Change `replay()` to call `Effect.runPromise(withTestClock(...))` directly. This keeps the boundary at the replay orchestrator.

Violation 2 (line 257 - `loadArtifact`): Convert from `async function` to a function returning `Effect.Effect<EvaluationArtifact | undefined>`. It simply delegates to `storage.get(traceId)` which already returns Effect. The caller `createReplayOrchestrator.replay()` should call it via `Effect.runPromise(loadArtifact(...))` at the boundary. But since `replay()` already has multiple boundary calls, compose them: create a `replayEffect` that composes `loadArtifact` + `withTestClock` and run the whole thing via a single `Effect.runPromise` at the end of `replay()`.
