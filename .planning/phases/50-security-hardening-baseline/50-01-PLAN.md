  <name>Task 1: Create security module and rate limiter with tests</name>
  <files>packages/dev/src/server/security.ts, packages/dev/src/server/rate-limiter.ts, tests/unit/dev/security.test.ts, tests/unit/dev/rate-limiter.test.ts</files>
  <behavior>
    - Auth: local IPs (127.0.0.1, ::1) bypass auth check -> returns allowed
    - Auth: non-local IP without Authorization header -> returns rejected
    - Auth: non-local IP with wrong token -> returns rejected
    - Auth: non-local IP with correct Bearer token -> returns allowed
    - Auth: when requireAuth=false -> all requests allowed regardless of origin
    - CORS: origin matching against allowlist with port wildcard (http://localhost:* matches http://localhost:3000)
    - CORS: origin not in allowlist -> matchOrigin returns false
    - CORS: exact origin match works (http://example.com matches http://example.com)
    - Rate limiter: first request within window -> allowed
    - Rate limiter: requests up to max -> all allowed
    - Rate limiter: request exceeding max -> rejected with retryAfterMs
    - Rate limiter: after window expires -> counter resets, allowed again
    - Rate limiter: cleanup removes stale entries
  </behavior>
  <action>
    Create `packages/dev/src/server/security.ts`:
    - Export `ServerSecurityConfig` interface with fields: requireAuth (boolean), authToken (string|undefined), corsAllowedOrigins (string[]), maxRequestBodySize (number), requestTimeoutSeconds (number), rateLimitMaxRequests (number), rateLimitWindowMs (number).
    - Export `DEFAULT_SECURITY_CONFIG` with: requireAuth=true, corsAllowedOrigins=['http://localhost:*', 'http://127.0.0.1:*'], maxRequestBodySize=1_048_576 (1MB), requestTimeoutSeconds=30, rateLimitMaxRequests=60, rateLimitWindowMs=60_000.
    - Export `isLocalRequest(ip: string): boolean` - checks against '127.0.0.1', '::1'.
    - Export `matchOrigin(origin: string, allowedOrigins: string[]): boolean` - supports `*` port wildcard by converting pattern to regex.
    - Export `checkAuth(ip: string, authHeader: string | null, config: ServerSecurityConfig): { allowed: boolean; status?: number }` - returns allowed for local IPs, checks Bearer token for non-local, returns 401 if requireAuth=true and token missing/invalid.
    - Read authToken from `FRED_DEV_SERVER_TOKEN` env var if not explicitly set in config.

    Create `packages/dev/src/server/rate-limiter.ts`:
    - Export `RateLimiter` class with constructor(maxRequests: number, windowMs: number).
    - Method `check(ip: string): { allowed: boolean; retryAfterMs?: number }` - sliding window per IP.
    - Method `cleanup(): void` - removes entries older than windowMs.
    - Internal cleanup interval (every 60s) with `dispose()` method to stop it.

    Create test files in `tests/unit/dev/` directory (create directory if needed). Tests exercise all behaviors listed above.
  </action>
  <verify>
    <automated>bun test tests/unit/dev/security.test.ts tests/unit/dev/rate-limiter.test.ts</automated>
  </verify>

    5. Add `dispose()` or cleanup for rate limiter in `stop()` method.
