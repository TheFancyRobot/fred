<objective>
Fix markdown formatting visibility in assistant messages by giving bold, italic, and heading scopes distinct foreground colors.

Purpose: UAT test 2 reported "the markdown is not rendered." Debug analysis confirmed the code IS correct -- SyntaxStyle registers all scopes, MarkdownRenderable produces correctly attributed StyledText chunks. The root cause is that `markup.strong` and `markup.italic` use the SAME foreground color (#e6e7ea) as the `default` scope. The only difference is the ANSI bold/italic attribute, which is invisible on terminals without distinct bold weight or italic font variants. The fix is to give these scopes visually distinct foreground colors so formatting is visible via COLOR alone, regardless of terminal ANSI attribute support.

Output: Updated theme.ts with visually distinct markdown scope colors.
</objective>

  <action>
In `packages/cli/src/tui/theme.ts`, update the `getMarkdownSyntaxTheme()` and `getStreamingMarkdownSyntaxTheme()` functions to give markdown formatting scopes visually distinct foreground colors. The changes ensure formatting is visible via COLOR regardless of whether the terminal renders ANSI bold/italic attributes.

**Changes to `getMarkdownSyntaxTheme()`:**

1. `markup.strong` -- Change foreground from `theme.fg.primary` (#e6e7ea) to `'#ffffff'` (pure bright white). Keep `bold: true`. The brighter white provides clear visual contrast against the default #e6e7ea text, and if bold renders too, it is even more distinct.

2. `markup.italic` -- Change foreground from `theme.fg.primary` (#e6e7ea) to `theme.fg.secondary` (#c2c6cc, a slightly dimmed blue-gray). Keep `italic: true`. The dimmer tone visually sets it apart from normal body text. If the terminal also renders italic, the effect compounds.

3. `markup.heading.1` / `markup.heading.2` / `markup.heading.3` -- Keep existing foreground `theme.accent.primary` (#5ec2c7 teal) and `bold: true`. Add `underline: true` so headings have an underline decoration for additional visual weight. Headings are already distinguishable via teal color, but the underline reinforces their role as section headers.

**Changes to `getStreamingMarkdownSyntaxTheme()`:**

1. `markup.strong` -- Change foreground from `theme.message.streamingFg` to `'#ffffff'` (pure bright white). Keep `bold: true`. During streaming, bold should still be visually distinct from amber default text.

2. `markup.italic` -- Change foreground from `theme.message.streamingFg` to `theme.fg.secondary` (#c2c6cc). Keep `italic: true`. The secondary color is dimmer than amber, providing distinction.

3. Headings -- Keep existing `theme.accent.primary` foreground and `bold: true`. Add `underline: true` to match the normal theme.

Do NOT change the `default`, `markup.raw`, `markup.list`, `punctuation`, or `punctuation.special` scopes -- they are fine as-is.
