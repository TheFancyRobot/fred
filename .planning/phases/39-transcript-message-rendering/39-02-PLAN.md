<objective>
Add tool call and task result rendering as inline expandable blocks with tree connectors within assistant message turns in the transcript.

Purpose: Tool calls are currently not visible in the TUI at all -- the stream event loop in chat.ts only forwards `token` events. This plan adds tool event forwarding, state tracking for tool blocks (in-progress, completed, errored), and visual rendering with tree connectors (`|` intermediate, `\u2514` last), braille spinner for in-progress, collapse/expand behavior, and distinct styling for tool vs task blocks.

Output: Tool calls render inline after assistant message content with file-tree-style connectors, smart collapse defaults, and error highlighting.
</objective>

**state.ts changes:**

Add tool block state types and management functions:

```typescript
export type ToolBlockStatus = 'in-progress' | 'completed' | 'errored';
export type ToolBlockKind = 'tool' | 'task';

export interface ToolBlockState {
  toolCallId: string;
  toolName: string;
  kind: ToolBlockKind;
  status: ToolBlockStatus;
  input: Record<string, unknown>;
  output?: unknown;
  error?: { message: string };
  startedAt: number;
  completedAt?: number;
  durationMs?: number;
  expanded: boolean;  // User-toggled expand state (overrides smart default)
}

export interface ToolBlockGroup {
  messageId: string;  // Which assistant message turn these belong to
  step: number;       // Which step in the conversation
  blocks: ToolBlockState[];
}
```

Add `toolBlocks` to `TuiState`:
```typescript
toolBlocks: {
  groups: ToolBlockGroup[];
  /** Map of toolCallId -> user-toggled expand override */
  expandOverrides: Record<string, boolean>;
};
```

Initialize `toolBlocks` in `createInitialTuiStateWithPlugins`: `{ groups: [], expandOverrides: {} }`.

Add pure state functions:
- `addToolCall(state, event: { messageId, step, toolCallId, toolName, input, startedAt, kind? })` -> `TuiState`: Adds a new tool block to the appropriate group (creating group if needed). Status `in-progress`, `expanded: true`.
- `completeToolCall(state, event: { toolCallId, output, completedAt, durationMs, error? })` -> `TuiState`: Updates matching block status to `completed` (or `errored` if error present). Smart collapse: if status `completed` and no error, set `expanded: false`. If errored, keep `expanded: true`.
- `failToolCall(state, event: { toolCallId, error, completedAt, durationMs })` -> `TuiState`: Updates matching block status to `errored`, keeps `expanded: true`.
- `toggleToolBlockExpand(state, toolCallId)` -> `TuiState`: Toggles expand state for a specific tool block.
- `getToolBlocksForMessage(state, messageIndex)` -> `ToolBlockState[]`: Returns tool blocks associated with the Nth assistant message (by matching the step/group ordering).
- `clearToolBlocks(state)` -> `TuiState`: Clears all tool block state (called on new message turn start).

**Determine tool vs task kind:** Use a heuristic -- if `toolName` starts with `task_` or `subagent_` or `handoff_`, set `kind: 'task'`. Otherwise `kind: 'tool'`. This can be refined later.

**app.ts changes:**

Add three new public methods to `FredTuiApp`:

1. `pushToolCall(event: { messageId: string, step: number, toolCallId: string, toolName: string, input: Record<string, unknown>, startedAt: number })`: Calls `addToolCall` on state, triggers `syncStateToUI`.

2. `pushToolResult(event: { toolCallId: string, toolName: string, output: unknown, completedAt: number, durationMs: number, error?: { message: string } })`: Calls `completeToolCall` on state, triggers `syncStateToUI`.

3. `pushToolError(event: { toolCallId: string, toolName: string, error: { message: string }, completedAt: number, durationMs: number })`: Calls `failToolCall` on state, triggers `syncStateToUI`.

Add a braille spinner animation timer: `private spinnerInterval: ReturnType<typeof setInterval> | null = null`. Start in `startAssistantStream` (every 80ms, call `syncStateToUI` if any tool blocks are in-progress). Stop in `completeAssistantStream` and `failAssistantStream`. Also stop in `stop()`.

**chat.ts changes:**

In the streaming loop (the `for await (const event of streamResult.fullStream)` block around line 255), add handlers for tool events alongside the existing token handler:

```typescript
for await (const event of streamResult.fullStream) {
  if (event.type === 'token' && event.delta) {
    app.pushAssistantToken(event.delta, 1);
  } else if (event.type === 'tool-call') {
    app.pushToolCall({
      messageId: event.messageId,
      step: event.step,
      toolCallId: event.toolCallId,
      toolName: event.toolName,
      input: event.input,
      startedAt: event.startedAt,
    });
  } else if (event.type === 'tool-result') {
    app.pushToolResult({
      toolCallId: event.toolCallId,
      toolName: event.toolName,
      output: event.output,
      completedAt: event.completedAt,
      durationMs: event.durationMs,
      error: event.error ? { message: event.error.message } : undefined,
    });
  } else if (event.type === 'tool-error') {
    app.pushToolError({
      toolCallId: event.toolCallId,
      toolName: event.toolName,
      error: { message: event.error.message },
      completedAt: event.completedAt,
      durationMs: event.durationMs,
    });
  }
}
```

**layout.ts changes:**

Add tree connector constants:
```typescript
const TREE_INTERMEDIATE = '\u2502';  // | vertical line
const TREE_LAST = '\u2514';          // \u2514 corner
const TREE_HORIZONTAL = '\u2500';    // - horizontal
const TREE_SPACE = ' ';

const BRAILLE_SPINNER_FRAMES = [
  '\u2807', '\u280B', '\u2819', '\u2838',
  '\u2830', '\u2834', '\u281C', '\u280E',
] as const;
```

Add tool block renderable builder functions:

1. `buildToolBlockRenderable(renderer, theme, block: ToolBlockState, isLast: boolean, id: string, nowMs: number)` -> `BoxRenderable`:
   - Container: `BoxRenderable` with `flexDirection: 'row'`, `paddingLeft: 2`, `paddingRight: 2`
   - First child: `TextRenderable` for tree connector character:
     - If `isLast`: `TREE_LAST + TREE_HORIZONTAL + TREE_SPACE` (e.g., `\u2514\u2500 `)
     - Else: `TREE_INTERMEDIATE + TREE_HORIZONTAL + TREE_SPACE` (e.g., `\u2502\u2500 `)  -- actually the intermediate connector should just be `\u2502  ` for vertical alignment with content below, and `\u2514\u2500 ` for last. Let me reconsider: for a single-line collapsed display, use `TREE_INTERMEDIATE` or `TREE_LAST` followed by a space.
     - Connector color: `theme.message.toolConnector` for tool kind, `theme.message.taskAccent` for task kind, `theme.message.errorAccent` for errored blocks
   - Second child: summary text:
     - If `status === 'in-progress'`: spinner frame + ` ${toolName}...` in `theme.fg.secondary`
       - Frame: `BRAILLE_SPINNER_FRAMES[Math.floor(nowMs / 80) % BRAILLE_SPINNER_FRAMES.length]`
     - If `status === 'completed'` (collapsed): `${toolName} \u2014 ${briefSummary}` in `theme.fg.dim`
       - `briefSummary`: truncate stringified output to ~60 chars, or "done" if output is empty/null
     - If `status === 'errored'`: `${toolName} \u2014 error: ${error.message}` in `theme.message.errorAccent`
   - If `block.expanded` and status is not `in-progress`:
     - Add a third child below the summary: `TextRenderable` with the full output (JSON.stringify with indent 2, truncated to reasonable length). Use `fg: theme.fg.dim` and `attributes: TextAttributes.DIM`.

2. `buildToolGroupRenderable(renderer, theme, blocks: ToolBlockState[], id: string, nowMs: number)` -> `BoxRenderable`:
   - If blocks.length === 0, return null/empty
   - Wrapper: `BoxRenderable` with `flexDirection: 'column'`, `marginTop: 0`, `marginBottom: 1`
   - For parallel tool calls (blocks.length > 1 where multiple are from same step):
     - If all collapsed AND all completed, show a summary line: `TextRenderable` with e.g. "3 tools" using `theme.fg.dim`
     - Otherwise, render each block individually using `buildToolBlockRenderable`
   - For each block, call `buildToolBlockRenderable` with `isLast = (index === blocks.length - 1)`
   - The group count header (e.g., "3 tools") is a `TextRenderable` with `fg: theme.fg.dim`

3. `getToolBlockSummary(output: unknown)` -> `string`: Utility to generate brief summary text from tool output. If string, truncate to 60 chars. If object with a `length` or `count`, show that. If array, show `${array.length} items`. Otherwise `JSON.stringify` and truncate.
