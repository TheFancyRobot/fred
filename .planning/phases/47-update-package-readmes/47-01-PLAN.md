# @fancyrobot/fred-{name}

[![npm version](https://img.shields.io/npm/v/@fancyrobot/fred-{name})](https://www.npmjs.com/package/@fancyrobot/fred-{name})

{One-line description from package.json}

## Installation

bun add @fancyrobot/fred-{name}

## Setup

Set your API key:

export {ENV_VAR}=your-api-key

## Usage

### Auto-Registration

Import the package to auto-register the provider:

import '@fancyrobot/fred-{name}';

This is the recommended approach -- the provider registers itself when imported.

### Programmatic

import { Fred } from '@fancyrobot/fred';
import '@fancyrobot/fred-{name}';

const fred = new Fred();
fred.registerDefaultProviders();

### Config File (YAML)

providers:
  - id: {provider_id}
    type: {provider_type}

### Agent File (.md)

---
id: my-agent
platform: {provider_id}
model: {example_model}
---

You are a helpful assistant.

## Supported Models

See [{Provider Name} documentation]({docs_url}) for available models.

## Related

- [Fred core](../core/README.md) -- main framework documentation
- [All packages](../../README.md) -- monorepo overview

## License

MIT
